❓ Help — 2 minute me setup

1️⃣ Free AI key lo (optional but recommended)

  1. console.groq.com kholo → Google/GitHub se sign in
  2. API Keys → Create API Key → copy karo
  3. Yahan ⚙ Settings me paste karke Save karo — bas, AI Team unlock ✅

Groq free tier: ~30 requests/min — ek team-run me 5 requests lagti hain, to kaafi chalega. Key sirf aapke browser me rehti hai aur seedha Groq ko jaati hai.

2️⃣ Apne computer pe chalao (real live data)

  1. Repo download karo → market-intel folder kholo
  2. Windows: run.bat double-click karo  |  Mac/Linux: terminal me ./run.sh
  3. Browser me http://localhost:8000 khul jayega — LIVE data ke saath

CLI report bhi hai: python report.py RELIANCE.NS AAPL --ai

🔍 Stock search (Groww jaisa)

  • Dashboard ke search box me naam likho — "reliance", "apple", "infosys"… suggestions aayengi, click karke add karo
  • Apne computer pe ye poora stock universe search karta hai (Yahoo se live) — NSE/BSE ke saare stocks + US
  • Indices bhi milte hain: "nifty", "sensex" · Crypto bhi: "bitcoin"

📱 Android/phone se kaise chalayein

  1. Header me 📱 Phone button dabao — QR code / address milega
  2. Phone aur computer same WiFi pe hon
  3. Phone browser me wo address kholo — bas! (Mac pe app chalti rahe)
